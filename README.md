## 1. 프로젝트 배경 및 목적

안면 마비 및 구음 장애(발음 장애) 환자의 재활은 지속적인 반복 훈련과 전문 의료진의 피드백이 필수적이다. 그러나 기존 방식은 환자가 직접 병원을 방문해야 하는 구조로, 이동이 어려운 환자에게 큰 부담이 된다.

본 프로젝트는 이러한 문제를 해결하기 위해 **원격 실시간 재활 모니터링 시스템**을 구현하는 것을 목표로 한다.

- 환자는 자택에서 재활 훈련 수행
- 의료진은 원격으로 환자의 상태를 실시간 모니터링
- 쌍방향 통신으로 즉각적인 피드백 제공

---

## 2. 시스템 개요

```
[ 의료진 서버 ]  ←──────────────────────────→  [ 환자 클라이언트 ]

  TCP Port 9997  ↔  재활 지시 문장 / 제어 명령    ↔  문장 수신 · 명령 처리
  UDP Port 9998  ←  환자 안면 영상 스트림          ←  영상 실시간 전송
  UDP Port 9998  →  의료진 영상 스트림             →  영상 실시간 수신
```

| 구성 요소 | 프로토콜 | 역할 |
|----------|----------|------|
| 의료진 서버 (`server.py`) | TCP + UDP | 재활 지시 전달 / 환자 상태 실시간 모니터링 |
| 환자 클라이언트 (`client.py`) | TCP + UDP | 미션 수행 / 영상·음성 실시간 전송 |
| TCP 소켓 (Port 9997) | TCP | 문장·분석 결과 — 손실 없이 정확하게 전달 |
| UDP 소켓 (Port 9998) | UDP | 영상·음성 스트림 — 저지연 양방향 실시간 전송 |

> 영상·음성은 단일 UDP 포트(9998)를 사용하며, 패킷 첫 바이트의 타입 값으로 구분한다.
> (`PKT_PATIENT_VIDEO`, `PKT_DOCTOR_VIDEO`, `PKT_PATIENT_AUDIO`, `PKT_DOCTOR_AUDIO`)

## 3. 주요 기능

### 3.1 의료진 측

- **재활 문장 하달** — 입력창에서 `/s 문장` 입력 시 환자 화면에 즉시 표시, 일반 텍스트는 지시사항으로 전달
- **실시간 영상 모니터링** — 환자의 안면 영상을 원격으로 수신 및 출력
- **의료진 영상 송신** — 의료진 카메라 영상을 환자 화면으로 실시간 전송
- **실시간 음성 청취 및 분석** — 환자의 목소리를 실시간 수신·재생하고, 발음 정확도·발화 속도·음량·음정 안정성·묵음 구간을 자동 분석
- **분석 데이터 시각화** — 안면 비대칭 수치와 음성 분석 결과를 그래프로 확인, 회차별 재활 추이 추적
- **환자 등록 및 관리** — 신규 환자 접속 자동 감지, 이름·ID 등록 및 저장, 정보 수정·삭제
- **환자 스토리 조회** — 회차별 세션 기록 및 재활 추이를 날짜별로 조회

### 3.2 환자 측

- **미션 문장 표시** — 의료진이 보낸 재활 지시 문장을 화면 상단에 크게 출력
- **의료진 영상 수신** — 의료진 카메라 영상을 화면에 실시간 표시
- **자세 유도 가이드** — 카메라 앞 올바른 자세(정면, 어깨 수평)를 화면 오버레이로 안내
- **카메라 피드 제공** — 가이드 마스크가 겹쳐진 본인 영상을 확인하며 자세 교정
- **음성 실시간 전송** — 마이크 입력을 즉시 의료진 서버로 전달
- **자체 분석 결과 확인** — 안면 비대칭 지수와 음성 분석 수치를 화면에서 직접 확인

## 4. 쌍방향 시나리오

```
① 의료진이 재활 문장 입력 → 환자 화면에 즉시 표시
        예) "아-에-이-오-우 를 천천히 반복하세요"

② 환자가 문장을 따라 발화하는 동안
   → 안면 영상 실시간 전송 (의료진 모니터에 출력)
   → 음성 실시간 전송 (의료진이 직접 청취)

③ 안면 비대칭 수치 + 발음 정확도 자동 계산
   → 분석 결과가 의료진 서버 그래프에 실시간 반영

④ 의료진이 결과를 보며 다음 문장 또는 피드백 전달
```

## 5. 핵심 기술 요소

| 기술 | 적용 내용 |
|------|----------|
| **TCP 소켓 통신** | 재활 지시 문장·분석 결과 전송 — 데이터 손실 없이 정확하게 전달 |
| **UDP 소켓 통신** | 영상·음성 실시간 스트리밍 — 저지연 전송으로 끊김 최소화 |
| **OpenCV** | 실시간 영상 캡처, 가이드 마스크 오버레이, 안면 비대칭 측정 |
| **sounddevice** | 마이크 입력 수집 및 수신 음성 실시간 재생 |
| **TTS** | 의료진이 하달한 문장을 자동으로 표준 발음 샘플로 생성 |
| **DTW (Dynamic Time Warping)** | TTS 샘플과 환자 발음의 시간축 패턴 흐름을 비교해 발음 정확도 측정 |
| **librosa** | 발화 속도, 음정 안정성(F0), 음량 변화, 묵음 구간 등 음성 특징 추출 및 분석 |
| **Dlib** | 68포인트 랜드마크 기반 안면 비대칭 측정 |
| **Python GUI** | 환자용·의료진용 대시보드 구성 (tkinter 기반) |

> **발음 정확도 측정 방식:** TTS로 생성한 표준 샘플과 환자 발음을 **DTW** 로 비교한다. FFT(주파수 스펙트럼 비교)는 TTS와 사람 목소리 간 파형 구조 차이로 수치 왜곡이 발생하므로 사용하지 않는다. DTW는 시간축 패턴 흐름 기준으로 비교하기 때문에 파형 구조 차이를 어느 정도 흡수할 수 있으며, librosa 내장 구현체를 활용한다.

## 6. 안면 비대칭 측정 알고리즘

> CNN/DNN 등 AI 기법은 사용하지 않는다.
> Dlib 68포인트 랜드마크 방식을 기본으로 사용하며, Optical Flow를 자세 유도 보조에 활용한다.

### 1. Dlib 68포인트 랜드마크 (채택)

| 항목 | 내용 |
|------|------|
| **방식** | ERT(Ensemble of Regression Trees) 기반 사전 학습 랜드마크 검출기 |
| **측정 방법** | 입꼬리·눈꼬리·눈썹 등 68개 좌표를 정밀하게 추출 → 좌우 대칭 좌표 간 거리 차이로 비대칭 지수 계산 |
| **장점** | 정확도 높음, 구현 간단, AI(CNN/DNN) 아님 |
| **단점** | Dlib 외부 라이브러리 추가 필요 |

### 2. Optical Flow (Lucas-Kanade) (자세 유도 보조)

| 항목 | 내용 |
|------|------|
| **방식** | 프레임 간 특징점 이동량을 추적하는 OpenCV 내장 알고리즘 |
| **측정 방법** | 어깨 등 신체 특징점 이동량을 추적해 자세 수평 여부 판정 |
| **장점** | OpenCV 순수 내장, 움직임 기반 측정으로 자세 유도에 적합 |
| **단점** | 정지 상태에서는 측정 불가, 초기 특징점 설정 필요 |

### 3. Active Shape Model (ASM) (검토 후 제외)

| 항목 | 내용 |
|------|------|
| **방식** | 얼굴 형태를 수학적 모델로 정의해 픽셀 경계를 따라가며 랜드마크를 찾는 방식 |
| **단점** | 구현 난이도 높음, OpenCV 미내장으로 직접 구현 필요 |

## 7. 기대 효과

- **접근성 향상** — 거동이 불편한 환자도 자택에서 전문 재활 훈련 가능
- **지속적 모니터링** — 방문 횟수에 관계없이 매일 재활 과정 기록·추적 가능
- **객관적 데이터 확보** — 의료진의 주관적 판단 보조를 위한 수치화된 재활 지표 제공
- **비용 절감** — 병원 방문 횟수 감소로 환자 및 의료 자원 비용 절약

## 8. 추가 예상 기능

### 8.1 재활 세션 기록 저장 (Excel + 영상/음성)

회차별 분석 결과를 엑셀 파일로 누적 저장하고, 영상 및 음성 파일도 함께 저장해 재활 진행 추이를 추적한다.

| 회차 | 날짜 | 비대칭 지수 | 발음 정확도 | 발화 속도 | 음량 | 묵음 구간 |
|------|------|------------|------------|----------|------|----------|
| 1 | 2025-03-01 | - | - | - | - | - |
| 2 | 2025-03-03 | - | - | - | - | - |

> 수치 기준은 실측 후 반영 예정. `openpyxl` 라이브러리를 활용해 매 세션 종료 시 한 행씩 자동 누적 저장한다.
> 영상은 `.avi`, 음성은 `.wav` 형식으로 날짜/회차별로 저장한다.

### 8.2 영상·음성 동기화 (Lip-sync)

영상(UDP Port 9999)과 음성(UDP Port 9998)이 서로 다른 포트로 수신되기 때문에, 네트워크 상황에 따라 입 모양과 소리가 어긋나는 현상이 발생할 수 있다. 각 패킷에 타임스탬프를 포함하여 수신 측에서 미세하게 맞추는 동기화 로직 추가를 검토한다.

### 8.3 캘리브레이션 단계 추가

안면 비대칭은 사람마다 기본 골격이 다르기 때문에, 측정 수치의 객관성을 높이기 위해 재활 시작 전 캘리브레이션 단계를 시나리오에 추가하는 것을 검토한다.

```
① 세션 시작 전 환자가 편안한 무표정 상태 유지
② 해당 상태를 기준점(Baseline)으로 측정 및 저장
③ 이후 재활 중 측정값을 기준점과 비교해 비대칭 지수 산출
```

### 8.4 자세 유도 가이드

안면 비대칭 측정의 정확도를 높이기 위해 환자가 카메라 앞에 올바른 자세로 앉도록 유도하는 기능을 추가한다.

```
① 세션 시작 전 환자 자세 확인
② 얼굴 중앙 정렬, 어깨 수평 여부를 화면 오버레이로 안내
③ 자세가 올바르면 세션 시작
```
